What Is Incident Triage?

Incident triage takes messy, unstructured diagnostic output and identifies the type of problem, where it's failing, and the most likely root cause — without you needing to know which specific tool to run first.

What Can I Paste Here?

Traceroute or MTR output, ping results, curl -v output, DNS resolution errors, SSL handshake failures, or server error logs. You can also upload a screenshot of any of these — a terminal window, an error dialog, or a browser's network panel — and the AI will read it directly. Either way, it classifies the input automatically and points you to the right follow-up tool.
